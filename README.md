# 🎵 Cifra → Holyrics V3

Versão 3 do conversor de cifras para Holyrics.

## Novidades V3

- Preview visual de TELA IGREJA
- Preview visual de RETORNO DE PALCO
- Navegação entre slides
- Contador de slides
- Análise da quantidade de linhas visíveis
- Comentários exclusivos do retorno
- Preview atualizado automaticamente ao editar o ChordPro
- Link do Cifra Club e modo manual

## Regra principal

Somente linhas de letra contam para paginação.

Comentários `{c: ...}`:
- aparecem no retorno
- não aparecem na tela da igreja
- não contam como linha
- podem ficar acima ou entre letras

## Instalação

```bash
npm install
npm run dev
```

Abra `http://localhost:3000`.
